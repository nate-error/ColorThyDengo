# ColorTheDengo
> Automated color by number bot for the Dengo coloring minigame (for the https://www.roblox.com/games/17007368718/Escape-Room game)
> Assisted by AI, cause it was painful work.

---

## What it does

1. Takes a screenshot (when you trigger it)
2. Reads the reference thumbnail to figure out what color each zone should be
3. Clicks the right color button, then clicks inside each zone for you

---

## Files

| File | Purpose |
|---|---|
| `calibrate.py` | Run once to tell the bot where things are on your screen |
| `color.py` | The actual bot, run this during the game |
| `config.json` | Generated by calibrate.py, stores your screen coordinates |

## Setup : run this once

**1. Open the game and get to the coloring screen**

**2. Run the calibration tool:**
```
python calibrate.py
```

A window opens showing the screenshot taken. Use the number keys to select which box to draw, then drag on the image:

| Key | What to draw |
|---|---|
| `1` | **BOX1**: the main drawing canvas (the big coloring area) |
| `2` | **BOX2**: the "TO COPY" thumbnail (top right, the small colored reference) |
| `3` | **BUTTONS**: the full color palette grid (all the color buttons) |
| `4` | **EXCLUDE** *(optional)*: any area to never click, like the STOP button |

Other controls:
- `R`: redo the current box if you drew it wrong
- `F5`: take a fresh screenshot (useful if the game moved)
- `S`: save and quit
- `ESC`: quit without saving

**3. Press `S` to save** necessary infos in `config.json` (after setting all the zones).

> You only need to redo calibration if you move the game window, change resolution, or change display scaling. Once its set, just run color.py.

## Usage :

**1. Start the bot:**
```
python color.py || or double click the script
```

**2. When the coloring 'minigame' appears, press `F7` and let it run** 

**3. Press `ESC` to quit the bot.**

## Config / tuning

At the top of `color.py`:

```python
DEBUG_DISPLAY = False # Set True to see a debug panel
ENABLE_MOUSE = True  # Set False to do a dry run with no actual clicks (pair with DEBUG_DISPLAY)
CLICK_DELAY = 0.01 # Seconds between zone clicks (You can try to tweak this value to get less zones missed
```
**If you want to check the color detection** before letting it click, set `DEBUG_DISPLAY = True`: it will show you a panel with:
- The reference thumbnail with snapped colors
- All detected zones with their click points
- A reconstructed preview of what it thinks the final result should look like

## How it works

### Color detection
- Samples the center of each color button to build a **palette** of valid colors
- Uses HSV saturation/value thresholds to ignore black outlines and white/grey backgrounds
- For each pixel in the reference thumbnail, snaps it to the nearest palette color by RGB Euclidean distance

### Zone detection
- Detects black outlines in BOX1 using HSV thresholding
- Uses `connectedComponentsWithStats` to find all enclosed zones
- Ignores tiny components (area < 80px) to filter out noise

### Color to zone mapping
- Auto detects the bounding box of the drawing inside each crop (handles padding differences between BOX1 and BOX2)
- Maps each pixel from BOX1 to its corresponding pixel in BOX2 using content-aligned normalized coordinates, ensuring good alignment.
- Each zone votes on its color: every pixel in the zone looks up its mapped BOX2 color, and the majority wins

### Click point calculation
- Uses progressive erosion to try to find an interior point in each zone
- Works correctly for any shape including crescents, pinched zones, and irregular polygons

### Mouse input
- Uses `ctypes.windll.user32.mouse_event` with `MOUSEEVENTF_ABSOLUTE` instead of `pyautogui` (pyautogui uses mouse calls ignored by roblox)
- `SetProcessDpiAwareness(2)` is called at startup so coordinates map correctly on scaled displays

## Troubleshooting

**"Palette empty" error**
-> Re-run `calibrate.py` and make sure the BUTTONS box covers all the color buttons fully.

**Colors are wrong**
-> Enable `DEBUG_DISPLAY = True`, check the "BOX2 snapped" panel. If it looks wrong, your BOX2 calibration box isn't covering the right area.

**Clicks land in the wrong place**
-> Enable DEBUG_DISPLAY to check the hits etc. Re-run `calibrate.py` after any resolution or scaling change.

**Some zones aren't getting colored**
-> Skill issues :). Raise `CLICK_DELAY` the game might not be processing clicks fast enough.

**STOP button is getting clicked**
-> Use key `4` in `calibrate.py` to draw an EXCLUDE zone over the STOP button area.
